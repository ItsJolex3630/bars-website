# 🏋️‍♂️ Bars Calistenics - Sitio Web Oficial

Repositorio de código limpio y producción para el despliegue de **Bars Calistenics** (Valencia, Venezuela) en **Cloudflare Pages**.

## 🌐 Despliegue en Cloudflare Pages
- **Proyecto:** `bars-website`
- **Dominio Pages:** `https://bars-website.pages.dev`
- **Rama principal:** `main`

## 🔒 Reglas de Seguridad
- El archivo `.gitignore` protege rigurosamente cualquier variable de entorno (`.env*`).
- Ningún secret o token debe subirse al repositorio.

## 📂 Contenido
- `index.html`: Landing page optimizada de alta conversión con catálogo de planes, coaches, galería, horarios e integración directa con WhatsApp.
- `wrangler.jsonc`: Configuración nativa para Cloudflare Pages.
